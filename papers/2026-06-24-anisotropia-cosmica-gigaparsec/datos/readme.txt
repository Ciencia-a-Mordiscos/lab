Data and Code Availability

This repository contains the data products used in the analysis presented in:

Detection of Anisotropic Cosmic Structures on a Gigaparsec  Scale
Francesco Sylos Labini & Marco Galoppo
Nature (2026)

⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻

1. DESI DR1 Data

The DESI DR1 galaxy catalogues used in this work are publicly available at:

https://data.desi.lbl.gov/doc/releases/dr1/

In particular, we use the:

* BGS (Bright Galaxy Sample)
* LRGS (Luminous Red Galaxy Sample)

catalogues.

⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻

2. Construction of Volume-Limited Samples

The construction of the volume-limited samples from the DESI BGS data — including:

* apparent magnitude selection,
* luminosity distance computation,
* K-correction,
* absolute magnitude estimation,

is described in Sect. 3.2 of:

https://www.aanda.org/articles/aa/full_html/2026/03/aa58271-25/aa58271-25.html

⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻

3. Angular Region Selection

The angular region denoted as R25 is selected following the procedure described in:

https://www.aanda.org/articles/aa/full_html/2026/03/aa58271-25/aa58271-25.html

⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻


4. Quasi-Two-Dimensional Samples

The galaxy distributions used for the ADPD analysis are constructed by selecting galaxies within quasi-two-dimensional regions of constant thickness, as described in the paper.

The corresponding data files are:

* points_LRGS.dat
* points_S1.dat
* points_S2.dat
* points_S3.dat
* points_S4.dat

Each file contains the projected galaxy positions used in the analysis.
